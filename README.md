# شجره‌نامه خانوادگی — نسخه عمومی

این نسخه فقط برای نمایش روی GitHub Pages است. اطلاعات افرادِ قابل‌خواندن از تصاویر ارسالی داخل `data.js` قرار داده شده و یک «لیست افراد» نیز به صفحه اضافه شده است.

## انتشار روی GitHub Pages
1. یک Repository بسازید، مثلاً `family-tree`.
2. فایل‌های `index.html`، `style.css`، `app.js` و `data.js` را در ریشه Repository آپلود کنید.
3. وارد Settings → Pages شوید.
4. در Build and deployment گزینه `Deploy from a branch` را انتخاب کنید.
5. Branch را `main` و Folder را `/(root)` انتخاب و Save کنید.
6. بعد از انتشار، GitHub لینک عمومی سایت را نشان می‌دهد.

## ویرایش اطلاعات فعلاً
اطلاعات نمونه در `data.js` است. برای هر فرد یک `id` یکتا و برای هر خانواده یک `union` تعریف کنید. فرزندان داخل `children` همان همسر مشخص قرار می‌گیرند؛ بنابراین چندهمسری با هم قاطی نمی‌شود.

> این نسخه هنوز پنل مدیریت و دیتابیس آنلاین ندارد؛ آن‌ها را در مرحله بعد به همین ظاهر اضافه می‌کنیم.
